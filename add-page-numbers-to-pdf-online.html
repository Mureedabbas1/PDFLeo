Add Page Numbers to a PDF

Page numbers make reports, handouts, contracts, and long documents easier to navigate. Choose a placement that does not cover existing text, footers, or important content, and review the exported pages.

Open Add Page Numbers to a PDF Tool

Step-by-step instructions

  1. Open Add Page Numbers and select the PDF.
  2. Choose the available placement, numbering style, and starting number.
  3. Run the operation and download the numbered PDF.
  4. Check the first page, a middle page, and the final page.
  5. Confirm numbers do not overlap existing content or printed page labels.

Tips for better results

  • Use a consistent margin so numbers do not sit on top of text.
  • For appendices, confirm whether numbering should continue or restart.
  • Keep the original if you need to change the numbering later.
Important: Keep an untouched original and verify the exported PDF before sharing it. Tool capabilities can vary with file structure and supported features.

Frequently asked questions

Can numbering start at a number other than 1?

Use a starting-number option if the tool provides one.

Can I skip the cover page?

Check whether page-range controls are available; otherwise the tool may number all pages.

Will the new numbers match printed page labels?

Not necessarily; printed labels may already exist and should be checked separately.
