    Tool availability and status

    Ready tools are intended for normal use; Beta tools need extra output checks. Some Ready tools, such as Protect, Unlock, Redact, PDF/A and Translate, still have important restrictions described on their cards. Available tools run locally in your browser, but some have limitations. PDF/A conversion uses Ghostscript WebAssembly and still needs separate validation for standards compliance. Password protection and unlocking use rasterized page output and may lose selectable text, links, forms and metadata. Redact covers a selected rectangle on rasterized pages and is not a certified specialist redaction workflow. Translation sends selectable text to a third-party service and exports text rather than preserving layout. Basic filling of supported existing PDF form fields is available; creating new fields is not. Compression and PDF/A conversion use a browser-based Ghostscript engine; review results because file-specific quality and standards compliance can vary. Optimize attempts Ghostscript-based optimization, and Repair cannot recover every damaged PDF. Some conversions export text rather than preserve original layout.

    Your files are yours

    PDF processing runs locally in your browser using a third-party PDF library. PDFLeo does not upload your selected files to its own server. For sensitive documents, use a device and browser you trust.

    FAQ

    Frequently Asked Questions

    Quick, honest answers about how PDFLeo works.

    Is PDFLeo free to use?
    The current public tools are offered free of charge, and no paid subscription is required to use the current tool collection. You can see optional plans on the plans page.
    Are my files uploaded to a server?
    Most tools process the files you select inside your own browser rather than uploading them to a PDFLeo file-processing server. Your browser may still request third-party libraries, and account or usage analytics requests can be sent to configured services. Translate PDF is different: it sends extracted text to the third-party MyMemory service. Read the Privacy Policy for details.
    Do I need to install anything or create an account?
    No installation is needed. PDFLeo is an online service that runs in your web browser and does not distribute a desktop application, installer or browser extension. You can use the tools without an account.
    Will conversions keep my original layout?
    Not always. Some conversions extract text and rebuild a simplified document rather than preserving original fonts, charts, images or page layout. Always compare the downloaded result with your original before relying on it.
    Are there file size limits?
    The homepage applies a limit of 25 MB per file and 60 MB per selection to help avoid excessive browser memory use. Large scans, OCR and image-heavy PDFs can still be slow depending on your device. Processing smaller batches helps.
    Can I use Protect, Unlock or Redact for sensitive documents?
    These tools are available, but they work by rasterising pages, so selectable text, links, forms and metadata may be lost, and redaction is not a certified specialist workflow. Use a copy of your file, check the output carefully, and use a validated tool for high-risk or regulated documents.
    Does PDFLeo work on a phone or tablet?
    Yes. The website is responsive and works in modern mobile browsers. Very large files may be slower on phones because processing uses your device’s memory.
    What if a tool fails?
    Try a valid, non-corrupt file, refresh the page and use an up-to-date browser. Keep a backup of the original document. More answers are on the full FAQ page.
