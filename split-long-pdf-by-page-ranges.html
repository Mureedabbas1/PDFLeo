How to Split a Long PDF by Page Ranges

Long PDFs are awkward. A 120-page policy manual, a scanned book chapter or a year of bank statements in one file is hard to email, hard to review and hard to hand to someone who only needs six pages of it. Splitting is the answer, but "split" can mean several different things: one file per page, one file per chapter, or just the pages someone asked for.

This guide explains how to plan a split, which PDFLeo tool fits each situation, and how to avoid the common slip of getting page numbers wrong.

Two tools, two jobs

It helps to know exactly what each tool does before you start, because the names can suggest more than they deliver.

  • Split PDF creates a ZIP archive that contains one PDF for every page, named page-1.pdf, page-2.pdf and so on. It does not ask for ranges. It is the right choice when you truly want every page as a separate file, for example to hand out single pages or process them one at a time.
  • Extract PDF Pages takes a page range such as 1-3,5 and saves exactly those pages as one new PDF. This is the tool for "give me chapter two" or "pages 14 to 22 only".
  • Remove PDF Pages works the other way round. You list the pages to delete and keep the rest. Handy when it is easier to name what you do not want.

So for splitting by ranges, you will use Extract once for each part you need. That sounds like extra work, but it gives you precise control and keeps each output file small.

Step 1: Make a split plan on paper

Open the PDF in any viewer and scroll through it. Write down where each section starts and ends, using the page numbers that your viewer shows in its page counter. This number may differ from the number printed on the page itself. A report with a cover, a contents page and roman-numeral front matter will have printed page "1" on something like the viewer's page 5. PDFLeo, like every other tool, counts physical pages from the start of the file, so use the viewer's counter.

A plan for a 60-page report might look like this:

  • Part 1, cover and contents: pages 1-3
  • Part 2, introduction and method: pages 4-15
  • Part 3, results: pages 16-41
  • Part 4, appendices: pages 42-60

Add the sizes up: 3 + 12 + 26 + 19 equals 60. If the total of your parts does not match the document length, you have a gap or an overlap in your plan. Catching that on paper is far quicker than finding it later.

Step 2: Extract each part

  1. Open Extract PDF Pages and choose your source PDF.
  2. Type the range for the first part in the box, for example 1-3.
  3. Run the tool and download the result.
  4. Rename the new file straight away, for example report-1-front-matter.pdf, so that you do not confuse it with the next output.
  5. Repeat for each range in your plan, always starting again from the original file.

Always start from the original, not from a previous output. Extracting from an extracted file means the page numbers have shifted, which is the most common cause of "I got the wrong pages".

How to write a page range

PDFLeo accepts a comma-separated list where each item is either a single number or a range with a hyphen:

  • 7 gives page 7 only.
  • 3-6 gives pages 3, 4, 5 and 6.
  • 1-3,8,12-14 gives pages 1 to 3, page 8, and pages 12 to 14 in a single file.

Some rules to be aware of. The first number of a range must not be larger than the second, so 6-3 is rejected. No page number may be below 1 or above the page count of the file, and the tool reports an error showing the total if you go past the end. Spaces around the hyphen are fine. Letters and other symbols are not.

One more detail that surprises people: the extracted pages come out in their original order, from lowest to highest, even if you type the numbers in a different sequence. Typing 9,2 still produces page 2 followed by page 9. If you need a different order, build the file first and then rearrange it with Organize PDF.

When one file per page is what you want

Use Split PDF when each page stands alone: individual invoices scanned in a batch, certificates, tickets, or exam sheets that go to different people. The ZIP it creates can be unpacked on any computer. A few points apply:

  • File names are numbered by page, not by content. If page 17 is Alice's invoice, you will have to rename page-17.pdf yourself.
  • A 200-page file becomes 200 files. Check that you really want that before you start.
  • The tool is labelled beta on the PDFLeo home page, so open a few of the output files and compare them with the original pages.

Splitting to get under a size limit

Email systems and web forms often reject attachments above a certain size. Splitting is a good fix because it keeps the full quality of each page. Estimate how many parts you need by dividing the file size by the limit and rounding up, then add one for safety because pages vary in weight: scans and photo pages are heavy, text pages are light.

If you would rather keep one file, the alternative is shrinking it. Our guide on choosing a compression level describes that trade-off. A combined approach also works: split off the heaviest pages and compress only those.

Checks before you send the parts

  • Open every output file and look at its first and last page. They should match the plan.
  • Confirm that the page counts of all parts add up to the original page count, unless you intentionally left sections out.
  • Look for a heading that starts on the last page of one part and continues on the next. Adjust the boundary by a page if so.
  • If the file contains private pages, double-check that none ended up in a part that goes to the wrong person. Redaction, not splitting, is the answer for hiding text inside a page.

Putting the parts back together

If a recipient later wants a single document again, you can recombine the parts with Merge PDF. Because the parts are numbered in your file names, merging them back in order is straightforward.

Frequently asked questions

Does splitting change the quality of the pages?

The tools copy pages into new documents rather than re-rendering them, so text and images are not recompressed. Always glance at the output to confirm.

Is my PDF uploaded when I split it?

No. The work is done in your browser, and the file is not sent to a PDFLeo server.

Can I split by bookmarks or chapter titles automatically?

Not at present. You choose the page numbers yourself, which is why the planning step above is worth doing.

Why does the tool say my range is invalid?

Usually the range runs past the last page, the start is bigger than the end, or there is a stray character. Check the total page count in your viewer and retype the range.
